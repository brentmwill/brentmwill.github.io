Bag End Fitz: privacy policy

Last updated 15 November 2026.

Bag End Fitz is a private tool with one user: the person who set it up and runs it on his own home server. This policy describes how it handles that person's Google user data.

What it accesses

With the user's permission, Fitz reads activity data (such as steps and calories burned) and sleep data from the Google Health API. Access is read-only. Fitz does not request any other Google data and never writes to the user's Google account.

How the data is used

The data is used for one purpose: to show the user summaries of his own activity and sleep, alongside goals he has set for himself. It is not used for advertising, is not sold, and is not used to build profiles of anyone.

Where it is stored

The data is stored in a database on the user's own home server, which is reachable only over his private network. Only the user's own account in the tool can read it.

Sharing

The data is not shared with or transferred to anyone else. The one exception is that the tool may send data to an AI service provider solely to produce the summaries shown to the user. No human reads the data apart from the user himself.

Google API Services User Data Policy

Bag End Fitz's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The user can delete the stored data at any time, since he runs the server it lives on. He can withdraw the tool's access at any time from his Google Account's third-party access page.

Contact

Questions can be sent to the maintainer through github.com/brentmwill.
